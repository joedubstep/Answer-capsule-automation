# Answer-capsule-automation

- [`film-room/`](film-room/): a single-page sales training room for care-home marketing calls. It has call-by-call tape review, AI sparring graded against a house playbook, an objection gauntlet, a cited proof book and a deal calculator. Build it with `python3 film-room/build.py film-room/data/example out.html`; see [film-room/README.md](film-room/README.md).

This repository is public. Only made-up example data lives here.
